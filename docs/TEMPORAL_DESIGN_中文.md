# 手术阶段识别：冻结 DINO 之上的离线时序网络

代码位于 `surgenet_dino/temporal/`，配置为 `configs/temporal.toml`。更新日期：2026-09-25（加入第 ⑤ 步顺序规则约束解码）。

范围：只使用 12 个有标注视频做训练和验证。所有数字都是固定四折、按整段视频分组的交叉验证开发估计，不是独立测试成绩。

## 一、方法

DINO 编码器全程冻结，不训练、不改动。预测时的输入是同一个视频全部 1 fps 帧的序列，不是单张图片。

```
每张图片
   │  ① 冻结的 SurgeNetXL DINOv2-B/14（336×336）
   ▼
每帧 1536 维特征 = [最后一层 CLS ‖ 最后一层 576 个 patch token 的均值]
   │  ② 按视频无标签标准化
   ▼
   │  ③ 线性分类头（留一视频交叉拟合）
   ▼
每帧 13 个阶段的对数概率
   │  把同一视频所有秒按时间排成序列
   │  ④ 时序网络：膨胀卷积 + 一层全局自注意力
   ▼
每一秒的阶段对数概率
   │  ⑤ 顺序规则约束解码（规则只从训练视频的标签序列读出）
   ▼
每一秒的阶段
```

### ① 特征

`cache-tokens` 从同一个冻结编码器取两样东西：最后一层的 CLS，以及最后一层全部 patch token 的均值。原有的特征缓存只存了 CLS，保持不动；新的特征缓存是独立文件，每一批提取时都与原缓存比对，CLS 部分必须一致（实测 74,430 行逐位相等），每次加载时还会重新校验原缓存的 sha、记录顺序、标签和编码器身份。

### ② 按视频无标签标准化

```
z_t = (f_t − μ_v) ⊘ σ_v
```

`μ_v`、`σ_v` 只用该视频自身的帧，不用任何标签，所以验证视频用完全相同的方式计算。它相当于语音识别里的倒谱均值方差归一化，用来消除患者、镜头和白平衡带来的整体偏移。

### ③ 交叉拟合的线性分类头

分类头就是已提交的正则化线性头（Dropout 0.1 → Linear，AdamW，lr 3e-4，权重衰减 0.05，标签平滑 0.05）。

它在见过的视频上约 96%，在新视频上约 76%。如果时序网络用分类头在训练视频上的输出来训练，它会学到“输入几乎总是对的”，到了新视频就失效。所以每个训练视频的概率都来自一个**没见过该视频**的头（留一视频），验证视频的概率来自用全部训练视频训练的头。头的训练轮数固定为 5，`fit_head_fixed` 没有验证集参数，结构上无法在验证数据上做任何选择。

### ④ 时序网络

每秒输入 51 维：13 维交叉拟合对数概率；标准化特征的 PCA-32（只在训练视频上拟合）；6 个可观测标志（该秒无图片、处于体外长间隙、在长间隙之后、相对进度、已用小时数、距长间隙结束的小时数）。输入不含任何标签。

- **预测级**：64 通道，10 层膨胀卷积（膨胀 1 到 512 秒），逐秒的通道 LayerNorm，没有 BatchNorm，dropout 0.3。
- **全局自注意力**：在预测级末端，把序列平均池化到 1/16 分辨率（约 350 到 560 个时刻），做一层 4 头自注意力，线性插值回原分辨率后作为残差加回：

  ```
  Attn(H)_i = Σ_j softmax_j( q_i·k_j/√d + b(i−j) ) v_j
  ```

  `b` 是带符号、按对数分桶的相对位置偏置，不使用绝对位置编码。每个时刻可以按内容查询整台手术里的其他时刻；权重取决于同一视频内部两个时刻的相似度，不受跨视频整体偏移的影响。
- **细化级**：48 通道，输入是预测级的概率。
- **损失**：两个级各自的掩码交叉熵加 0.15 倍截断的对数概率平滑项。
- **针对只有 9 条训练序列的正则**：分段速度扭曲 0.7 到 1.4 倍、随机裁剪、18 到 300 秒的跨度掩码、对数概率噪声、按“未见视频上的混淆矩阵”做的段级扰动。
- **训练轮数**：候选为第 10、20、…、60 轮。在训练视频内部做 3 折交叉验证，选一个公共轮数，再用全部训练视频按这个轮数重新训练。5 个种子的输出取平均。
- 参数量约 30 万。

体外段在数据里已被剔除，它在时间线上留下的空洞可以直接从帧号看到，不需要标签。12 个视频都有且只有一段不少于 880 秒的长空洞，次长的不超过 104 秒。

### ⑤ 顺序规则约束解码

代码在 `surgenet_dino/temporal/constraints.py`。有些事实在每一台手术里都成立：IMA 处理（3）只有一段，之后不会再出现阶段 2；直肠切离相关场景（81）一旦开始，0 到 7 都不会再出现。时序网络大多数时候遵守这些事实，但不总是。例如视频 14，网络在真实 81 开始前 3 分钟就判成 81，随后又回到 7。

每一折只从 9 个训练视频的标签序列里读出两类规则，只保留在全部训练视频中都成立、并且至少有一个视频同时包含相关阶段的规则：

| 规则 | 含义 | 每折数量 |
|---|---|---|
| 先后 a → b | 每个训练视频里，a 的最后一秒都在 b 的第一秒之前。解码时 b 一旦开始，a 就不能再出现 | 51 到 54 条，例如 2 → 3、0…7 → 81、82 → 83 |
| 单段 m | 每个训练视频里，m 都只有连续的一段。解码时离开 m 之后就不能再回到 m | 3、6、82、9、13；第 3 折（05 不在训练集）另有 83 |

解码是精确的 Viterbi 搜索。状态是"当前阶段 + 哪些受约束的阶段已经开始过"；四折里受约束的阶段都是 3、4、6、7、81、82、83、9、13 这 9 个，即 512 × 13 个状态。在满足全部规则的前提下，最大化网络逐秒对数概率之和：

```
ŷ = argmax_y Σ_t log p_t(y_t)    约束：y 满足该折训练视频读出的全部规则
```

它和否决过的马尔可夫链不同：没有转移概率，没有时长，也没有任何可调参数。规则是硬性的、跨越整台手术的"不可逆事件"，而不是相邻两秒之间的软偏好。网络输出不违反任何规则时，结果就等于直接 argmax。每个视频在 CPU 上约 5 秒。

写出的概率仍是网络的概率。在规则改动了标签的那些秒，把网络原来的最高类和解码结果那一类的概率互换，每一行仍是一个分布，argmax 等于解码结果。

## 二、无泄漏的评估协议

固定四折 `configs/cv4_reference.json`。对每一折，留出 3 个视频作验证集，其余 9 个为训练集：

1. 每个视频只用自身帧做标准化。
2. 在 9 个训练视频上做留一视频交叉拟合，得到它们的视频外概率；用 9 个视频的全量头给验证视频产生概率。
3. 时序网络的轮数只在 9 个训练视频内部选择。内层 3 折严格重新嵌套：每个内层折有自己的交叉拟合头、PCA 和网络。
4. 用 9 个训练视频按选定轮数重新训练 5 个种子，预测 3 个验证视频。
5. 从 9 个训练视频的标签序列读出顺序规则，用它们解码 3 个验证视频。验证视频的标签不参与以上任何一步。

测试用调用记录证明：验证视频从未进入任何拟合、选择或规则读取调用，内层折连验证视频的特征都不读取。

## 三、如何运行

```bat
:: 1. 提取特征（约 20 分钟，与原缓存校验通过才会写入）
scripts\temporal.bat cache-tokens --features <features.pt> --output-dir <特征目录>

:: 2. 四折交叉验证（约 40 分钟，单卡）
scripts\temporal.bat cv --features <features.pt> --tokens <特征目录> --baseline <基线 csv> --output-dir <新目录>

:: 3. 学习曲线诊断（只画曲线，不做任何选择），再出图
scripts\temporal.bat curves --features <features.pt> --tokens <特征目录> --reference-result <第 2 步的 result.json> --output-dir <新目录>
uv run --isolated --no-project --with matplotlib==3.11.2 python scripts\plot_temporal.py <新目录>
```

输出目录必须是新目录。`cv` 的主要文件：`result.json`、`summary.csv`（逐帧头、网络直接 argmax、约束解码三行）、`fold_metrics.csv`（含网络 argmax 准确率和规则改动的秒数）、`video_metrics.csv`、`segment_metrics.csv`、`validation_predictions.csv`（约束解码结果，与基线同格式）。每折实际读出的规则写在 `result.json` 的 `selections[].order_rules`。

## 五、已知局限

- **开发估计。** 嵌套保护了训练轮数的选择和顺序规则的读取，但不保护方法本身的设计。方法是在这同样 12 个视频、同样四折上确定的。
- **离线。** 标准化用了整段视频的统计量，时序网络会读取未来帧，所以它不能对孤立的单张图片预测，也不是术中实时模型。
- **短阶段。** 阶段 82（每个视频只有 12 到 92 秒）仍是最弱的一类。
- **少数视频整段误判。** 剩下的错误主要是个别视频里持续数分钟的整段误判，视频 05 和 08 一直最低。这属于个别手术的画面与其他手术差别大，9 台训练手术覆盖不了。
- **依赖长空洞标志。** 12 个视频都有一段长空洞。没有长空洞的视频相应的两个标志恒为 0，这种情况只有合成测试覆盖。
- **约束会吃掉短阶段。** 为了满足规则，解码器选总代价最小的改法，可能把一小段其实判对的阶段删掉。视频 14 的阶段 3（IMA 处理，约 1 分钟）之后网络又判回 2，解码器把这段 3 改成了 2，而不是把后面的 2 改成 4；阶段 3 的 F1 因此下降约 0.03。加"4 之前必须出现过 3"这类前提规则只改变 1 到 2 帧，没有采用。
- **规则只来自 9 个训练视频。** 12 个验证视频里有 3 个本身就违反了所在折读出的某条规则：05（83 之后回到 81，83 有两段）、12（6 之后又出现 0）、08（7 之后又出现 0、5、6）。它们在解码后都没有变差，因为网络在那些位置本来就没有给出违反规则的判断。但对新视频，真实流程违反规则的片段会被强行改错，这是这一步的主要风险。

## 六、做过但没有采用的方案

下面的数字都是同一协议下的四折嵌套结果，除非另有说明。相关代码已移除，只保留结论。

| 方案 | 结果 | 结论 |
|---|---|---|
| 逐帧线性头，768 维 CLS（已提交的基线） | 76.69% | 起点 |
| 基线概率接马尔可夫链（转移计数加后验解码），零训练 | 84.24% | 时间结构约 +7.5 个点 |
| 再加按视频标准化和交叉拟合 | 86.19% | 标准化约 +4 个点 |
| 再加负二项显式时长 | 86.18% | 无增益 |
| 无顺序先验的视频内标签传播（闭式解，零训练） | 85.08% | 不如链 |
| 时序卷积网络单独 argmax，CLS | 88.66% | 不接链也不低于接链的 87.93% |
| 时序 U-Net，有无瓶颈注意力（第 3 折内层） | 低 2.2 到 2.7 个点 | 更差，预测更碎 |
| 分类头与时序网络合并训练（第 3 折内层） | 低 0.7 个点，验证视频低约 2 个点 | 没有更好 |
| 最后 4 层 CLS 加 patch 均值，3840 维（第 3 折内层） | +0.4 | 不显著 |
| “已开始、已彻底结束”序数辅助头（第 3 折内层） | 无差别 | 无作用 |
| 时序卷积加全局注意力，CLS | 88.59% | 与 88.66% 持平 |
| 时序卷积，CLS 加 patch 均值 | 88.60% | 持平，最差视频 78.0% 到 82.5% |

两条方法论教训：单折上超过一个标准误的增益（+1.3 和 +1.6）到四折都消失了；直接在验证视频上挑超参数会让单折虚高约 2 个点。

### 第三轮（2026-09-23）：在第 3 折上探索 90% 的尝试

起因是一份外部分析，它建议优先检验种子融合方式、PCA 维数和“细化级重新读取视觉输入”。这些和几项自选方向都在第 3 折（验证视频 05、12、16）上实测，评判方式不变：先看 9 个训练视频内层交叉验证的变化，再看验证集。同一配置换一个全局随机种子重跑，验证集相差 0.15 个点、内层相差 0.5 个点，这是本折的噪声尺度。

| 变体 | 逐帧头 | 网络（验证集） | 内层 | 结论 |
|---|---:|---:|---:|---|
| 参考（两次运行） | 76.1% | 88.41% / 88.26% | 88.50% / 89.03% | 噪声尺度 |
| 10 个种子 | 76.1% | 88.69% | 88.88% | 约 +0.3，集成接近饱和 |
| 算术融合代替几何融合 | 76.1% | 88.33% | 88.44% | 只有 126 帧不同，无差别 |
| dropout 0.5 | 76.1% | 87.69% | 88.39% | 无 |
| PCA 1 / 16 / 64 / 128 | 76.1% | 87.51 / 87.24 / 86.69 / 85.54% | 88.45 / 87.79 / 88.96 / 86.63% | 32 是局部最优；扩维更差 |
| 细化级重读视觉输入（含残差版） | 76.1% | 86.78% / 87.56% | 88.66% | 更差，每视频段数翻倍到 43 |
| MLP 逐帧头 | 76.4% | 87.49% | 89.28% | 内层 +0.8 但验证集 −0.9，噪声 |

诊断数字（参考行，19,179 个验证帧）：网络错 2222 帧，其中 32% 的置信度超过 0.9；5 个种子里任一个答对的上限 93.2%，10 个种子 94.8%；细化级相对预测级净修复 +97 帧；逐帧头错而网络对的有 3017 帧，反向的 649 帧。

结论：在冻结 DINO、13 个阶段、9 个训练视频的条件下，没有一项改动能在噪声之外超过现有方案；剩余错误是少数视频里置信度很高的整段误判，单帧证据决定了它们。想再往上走，需要更多有标注的手术，或者不再冻结主干。

### 第四轮（2026-09-24 到 09-25）：输入几何、五个外部思路，采用约束解码

先在同一天把参考方案按同样配置重跑了一次，作为噪声尺度：四折合并 89.02%，原来是 88.79%，单折最多相差 0.7 个点，单个视频最多 2.3 个点。下表中的比较都与这次重跑配对。

| 方案 | 结果 | 结论 |
|---|---|---|
| 保持宽高比输入（1280×720 → 336×588，位置编码 24×24 插值到 24×42） | 逐帧头 +0.75，四折全部上升；网络 89.04% 对 89.02%，各折 +1.5 / +0.3 / +0.5 / −2.3 | 无效。第 3 折单独看是 +0.5，四折合并为零；第 4 折的下降来自视频 03、08 里阶段 0/5 各占一半证据的片段整段翻转，与轮数选择无关 |
| **顺序规则约束解码（第一条思路：不可逆事件）** | 三份独立网络输出上 +0.30 / +0.31 / +0.55；F1@0.75 +2.6 到 +3.7 | **采用**，即第 ⑤ 步 |
| 约束解码再加"前提"规则（b 开始前 a 必须出现过） | 只改变 1 到 2 帧 | 不需要 |
| "做什么"辅助头（6 类活动：内侧游离、外侧游离、血管处理、系膜处理、切离吻合、其他，权重 0.5） | 88.25%，−0.77，8 个视频下降 | 无效。辅助目标由同一套阶段标签推出，没有新信息，与序数辅助头相同 |
| 无标签的 patch 组成直方图（32 个视觉词）和 VLAD 地点描述子（PCA-128） | 逐帧头 +0.04 / +0.21；同一视频内最相似 10 帧属于同阶段的比例 72.1%，现有特征是 74.0% | 无效，未跑时序网络 |
| 长空洞后 81 → 83 → 13 的时长先验 | 空洞后 81 持续 4 到 428 秒（中位 56 秒） | 没有可用的时长规律 |
| 关键器械时间线（81/83） | 81 与 83 的分界处，吻合器部件在两侧都出现，插入吻合器可能不在视野内 | 前提不成立，未做；82 和 3 的错误合计约 0.8 个点，需要人工标注 |
| 解剖结构相对位置 | 需要 IMA 等结构的分割标注 | 未做 |

阶段 0 和 5 的混淆（约占错误的 9%）主要来自标注约定：阶段 0 的后段常已在用能量器械分离，画面与训练视频 12、13、14 开头紧接在 0 后面的阶段 5 相同，区别在于标注者认为正式步骤是否已经开始。这类错误无法靠特征解决。
